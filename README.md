# শব্দের আড়ালে (Shobder Arale)
### একটি নিভৃত, শান্ত ও রুচিশীল ব্যক্তিগত বাংলা সাহিত্য পোর্টাল

"শব্দের আড়ালে" হলো একজন সাহিত্যিকের একক ওয়েবসাইট যেখানে কেবলমাত্র স্বত্বাধিকারী কবিতা, উপন্যাস, ছোটগল্প ও ব্যক্তিগত চিন্তাভাবনা প্রকাশ করেন। পাঠকেরা কোনো অ্যাকাউন্ট বা সাইন-ইন ছাড়াই নির্বিঘ্নে সমস্ত প্রকাশিত সাহিত্য উপভোগ করতে পারবেন।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Features)

1. **পাঠকবান্ধব স্নিগ্ধ নকশা (Literary Editorial Design):**
   - উষ্ণ আইভরি ও প্রাচীন কাগজের আবহ (`#FAF7F2`), আরামদায়ক গাঢ় চারকোল টেক্সট ও মৃৎশিল্প-রঙিন অ্যাকসেন্ট।
   - গুগল ফন্টসের **Noto Serif Bengali** (সাহিত্য রচনার জন্য) এবং **Noto Sans Bengali** (ইন্টারফেসের জন্য)।
   - পড়ার সুবিধার্থে হরফের আকার পরিবর্তন (ছোট, মাঝারি, বড়, সুবিশাল) এবং ৩টি পাঠ-থিম (আইভরি, প্রাচীন কাগজ, রাত্রিকালীন অন্ধকার)।
   - কবিতার পঙ্‌ক্তি ও স্তবক বিন্যাস (Stanza Preservation) এবং প্যারাগ্রাফ রিদম।

2. **পাবলিক পেজসমূহ (Public Pages):**
   - **প্রচ্ছদ (Home):** সাহিত্যিক ভূমিকা ("কিছু অনুভূতি শব্দেই বেঁচে থাকে…"), নির্বাচিত রচনা, সাম্প্রতিক কবিতা, ছোটগল্প এবং চলমান/সমাপ্ত উপন্যাসের হালনাগাদ।
   - **কবিতাগুচ্ছ (Poetry):** প্রকাশিত কবিতাসমূহের তালিকা, শিরোনাম বা পঙ্‌ক্তি অনুসন্ধান, বিষয়ভিত্তিক ট্যাগ ফিল্টারিং এবং পেজিনেশন/লোড-মোর।
   - **উপন্যাস ও ধারাবাহিক আখ্যান (Novels):** চলমান ও সমাপ্ত উপন্যাসের তালিকা, সারসংক্ষেপ, কভার চিত্র, এবং প্রতিটি উপন্যাসের অধ্যায়ভিত্তিক সূচিপত্র।
   - **অধ্যায় পাঠ (Novel Chapter Reader):** সুনির্দিষ্ট অধ্যায় পাঠের পাতা, পূর্ববর্তী ও পরবর্তী অধ্যায় নেভিগেশন।
   - **ছোটগল্প সম্ভার (Stories):** বিভাগভিত্তিক ছোটগল্প তালিকা, পড়ার আনুমানিক সময় (Reading Time) ও নির্যাস।
   - **বিস্তারিত পাঠ পাতা (Writing Detail):** কবিতা ও গল্পের স্বতন্ত্র পাঠ পাতা, লিঙ্ক কপি ও সোশ্যাল শেয়ার অ্যাকশন, একই বিভাগের সম্পর্কিত রচনার সুপারিশ।
   - **লেখক পরিচিতি (About Author):** সম্পাদনাযোগ্য জীবনী, সাহিত্য ভাবনা ও সামাজিক যোগাযোগের লিঙ্ক।
   - **সাহিত্য অনুসন্ধান (Search):** বাংলা হরফে যেকোনো শব্দ বা শিরোনাম অনুসন্ধান (খসড়া বা অপ্রকাশিত লেখা কখনোই সার্চে প্রদর্শিত হয় না)।

3. **সুরক্ষিত লেখক ড্যাশবোর্ড (Secure Admin Dashboard - `/admin`):**
   - কঠোর জিরো-ট্রাস্ট অনুমোদন: কোনো সাধারণ দর্শক নিজেকে প্রশাসক হিসেবে সাইন-আপ করতে পারে না।
   - পরিসংখ্যান: মোট প্রকাশিত লেখা, খসড়া রচনা, উপন্যাস ও অধ্যায়ের সংখ্যা।
   - আরামদায়ক বাংলা এডিটর, খসড়া সংরক্ষণ (Autosave Drafts), লাইভ প্রিভিউ ও প্রকাশের ব্যবস্থা।
   - উপন্যাস ও অধ্যায় ব্যবস্থাপনা: অধ্যায় নম্বর নির্ধারণ ও অধ্যায়ের ক্রম বিন্যাস।
   - ধ্বংসাত্মক কাজের পূর্বে বাংলা কনফার্মেশন মোডাল।

## 🛠️ প্রযুক্তি কাঠামো (Tech Stack)

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS (কাস্টম বাংলা ফন্ট ও সাহিত্যিক থিম ভেরিয়েবল সহ)
- **Database:** Google Cloud Firestore (Modular Firebase Web SDK v11+)
- **Authentication:** Firebase Authentication (Email/Password & Google Sign-In with Firestore allowlist)
- **Hosting:** Firebase Hosting (SPA rewrites)

## 📋 ধাপ-ভিত্তিক প্রোডাকশন সেটআপ নির্দেশিকা (10-Step Guide)

### ১. ডিপেনডেন্সি ইনস্টল করুন
প্রজেক্ট ফোল্ডারে টার্মিনাল খুলে কমান্ড চালান:
```bash
npm install
```

### ২. ফায়ারবেস প্রজেক্ট তৈরি করুন
- [Firebase Console](https://console.firebase.google.com/) এ গিয়ে **Add project**-এ ক্লিক করুন।
- প্রজেক্টের একটি নাম দিন (যেমন: `shobder-arale-portal`) এবং প্রজেক্ট তৈরি সম্পন্ন করুন।

### ৩. Web App রেজিস্টার ও ক্রেডেনশিয়াল সংগ্রহ করুন
- প্রজেক্ট ওভারভিউ পেজে **Web (`</>`)** আইকনে ক্লিক করুন।
- অ্যাপের নাম দিন (যেমন: `Shobder Arale Web`)।
- প্রদর্শিত `firebaseConfig` অবজেক্ট থেকে কী-গুলো সংগ্রহ করুন।

### ৪. Authentication সক্রিয় করুন
- বামপাশের মেনু থেকে **Build > Authentication**-এ যান।
- **Get Started**-এ চাপ দিয়ে **Sign-in method** ট্যাবে যান:
  - **Email/Password** প্রোভাইডার চালু (Enable) করুন।
  - **Users** ট্যাবে গিয়ে **Add user** বাটনে ক্লিক করে লেখকের ব্যক্তিগত ইমেইল ও একটি শক্তিশালী পাসওয়ার্ড দিন।
  - তৈরি হওয়া ব্যবহারকারীর **User UID** কপি করে রাখুন।

### ৫. Cloud Firestore ডাটাবেজ তৈরি করুন
- বামপাশের মেনু থেকে **Build > Firestore Database**-এ যান।
- **Create database**-এ ক্লিক করে আপনার পছন্দের লোকেশন নির্বাচন করুন।

### ৬. এনভায়রনমেন্ট ভেরিয়েবল (.env) ফাইল তৈরি করুন
- প্রজেক্টের রুটে `.env.example` ফাইলের অনুকরণে একটি `.env` ফাইল তৈরি করুন:
```env
VITE_FIREBASE_API_KEY="AIzaSy..."
VITE_FIREBASE_AUTH_DOMAIN="your-project-id.firebaseapp.com"
VITE_FIREBASE_PROJECT_ID="your-project-id"
VITE_FIREBASE_STORAGE_BUCKET="your-project-id.appspot.com"
VITE_FIREBASE_MESSAGING_SENDER_ID="123456789"
VITE_FIREBASE_APP_ID="1:123456789:web:abcdef"
```
*(সতর্কতা: কোনো অবস্থাতেই Firebase Admin SDK-এর প্রাইভেট কী বা সার্ভিস অ্যাকাউন্ট ফাইল ফ্রন্টএন্ড কোডে যুক্ত করবেন না)*

### ৭. লোকাল ডেভেলপমেন্ট সার্ভার চালু করুন
লোকালি চালিয়ে দেখতে রান করুন:
```bash
npm run dev
```
ব্রাউজারে `http://localhost:3000` ঠিকানায় ওয়েবসাইটটি দেখতে পাবেন।

### ৮. প্রথম প্রশাসক অনুমোদন নিশ্চিতকরণ (Bootstrap Admin)
স্বত্বাধিকারীর অ্যাকাউন্টকে লেখক হিসেবে অনুমোদন দিতে:
1. Firebase Console-এ **Firestore Database > Data** ট্যাবে যান।
2. **Start collection**-এ ক্লিক করুন:
   - Collection ID: `admins`
   - Document ID: আপনার ধাপ ৪-এ কপি করা লেখকের **User UID**
   - Field: `role` (string) = `"owner"`
   - Field: `email` (string) = লেখকের ইমেইল
3. সেভ করুন। এখন শুধুমাত্র আপনার অ্যাকাউন্ট দিয়েই `/admin` ড্যাশবোর্ডে লগইন করা যাবে।

### ৯. জিরো-ট্রাস্ট Firestore Security Rules ডেপ্লয় করুন
প্রজেক্টের `firestore.rules` ফাইলে অন্তর্ভুক্ত কঠোর রুলসগুলো ডেপ্লয় করতে Firebase CLI দিয়ে চালান:
```bash
firebase deploy --only firestore:rules
```

### ১০. Firebase Hosting-এ প্রোডাকশন ওয়েবসাইট ডেপ্লয় করুন
ওয়েবসাইটটি বিল্ড ও পাবলিশ করতে টার্মিনালে রান করুন:
```bash
npm run build
firebase deploy --only hosting
```
ডেপ্লয়মেন্ট সম্পন্ন হলে আপনার প্রাপ্ত ফায়ারবেস হোস্টিং ডোমেইনে ওয়েবসাইটটি বিশ্বজুড়ে পাঠকদের জন্য সক্রিয় হয়ে যাবে!

## 🔒 নিরাপত্তা নিয়মাবলী (Security Model)

- **অননুমোদিত পাঠক:** শুধুমাত্র `status == "published"` যুক্ত কবিতা, উপন্যাস এবং অধ্যায় পড়তে পারবে। কোনো খসড়া (`draft`) ডাটাবেজ থেকে রিকোয়েস্ট করলেও ফায়ারস্টোর পারমিশন ডিনাইড করবে।
- **লেখক/স্বত্বাধিকারী:** শুধুমাত্র `admins/{uid}` কালেকশনে অন্তর্ভুক্ত অ্যাকাউন্ট সব ধরনের সৃষ্টি রচনা, সম্পাদনা, প্রকাশ ও মুছে ফেলার অধিকার পায়।
- **সেলফ-রেজিস্ট্রেশন ব্লকার:** কোনো বহিরাগত দর্শক নিজেকে অ্যাডমিন বানাতে পারবে না, কারণ সিকিউরিটি রুলসে `admins` কালেকশনের রাইট পারমিশন ক্লায়েন্ট SDK থেকে সম্পূর্ণ নিষিদ্ধ করা হয়েছে।
